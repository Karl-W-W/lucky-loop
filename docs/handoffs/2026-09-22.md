## PRINCIPLES

1. **A price card is facts; a hero is where promotion hides.** The council's risk seat put it in one
   line and it held under every persona: state only what runs today beside the price, derive every
   number at build, never type a maturity sentence by hand. The critic pass then caught exactly that
   — a hand-typed "three document types" in the AGB had already drifted from the derived four.
2. **Legal text is content with a gate, not code with a lawyer.** Karl edits two JSON files and four
   markdown files; the build refuses placeholders and disagreements. What the gate cannot do is judge
   truth, and it says so in its own header.
3. **Every claim in the map was re-run by someone else before it was shown.** 13 of 25 confirmed, 11
   refined, 1 refuted outright (the dead-man had been a Cloudflare Worker for twelve days while the
   roster said GitHub Actions). The refuted one had been copied from AGENT-OS — the vault can be the
   source of a wrong claim as easily as a right one.
4. **A refuser per finding beats a longer critic.** Two of four serious critic findings died on
   contact (the "billed via Stripe" objection was false on inspection; the mailto CTA sat beside an
   equally visible "Ask a question"). Applying them would have made the page less true.
5. **The drift gate refuses config edits it cannot see the reason for.** A one-line
   `poweredByHeader: false` tripped the canvas drift check because the canvas excerpts
   `next.config.ts`; the edit was dropped rather than the canvas regenerated inside a Stripe PR.
6. **Headless Chrome's `--window-size=320` is not a 320 px test.** It clamps to a minimum window and
   crops, so both prod and the branch looked broken. Real mobile emulation over CDP (puppeteer-core,
   `isMobile: true`) measured scrollWidth = 320 on every page.
