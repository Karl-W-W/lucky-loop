## PRINCIPLES

None of these is ratified. They are what tonight's failed checks taught, each with its incident.

- **A new test is a test only once it has failed with the fault put back.** One of tonight's tests
  passed with the fault in place: two processes shared a single "busy" look and the other one took it.
  It was replaced, and each key test was then run against the broken code first.
- **The process that dials must be the one that survives, and every dial gets its follow-up step at
  once.** Rounds one and two of the dial fix each left a real call with nobody to file it, hand it over
  or retry it: first when a run was cut off while it watched, then when a time limit was put on the
  request that places the repeat.
- **Act on a field nobody documented only on the exact shape that was seen, read twice by looks that
  came back.** What the vendor's record says while a phone rings has not been seen. One look that
  failed was at first counted as a second look.
- **A printed line must be true at the moment it is said.** The script said "not dialled a third time"
  while the hourly retry was still scheduled, and "it is dialled once more now" before the process that
  dials had decided.
- **Verified is not landed.** A row can read verified while its work sits on a branch. Fetch, read
  the worker's session, merge, push.
- **Read the other side's own page before choosing a rhythm.** The board row said to refresh the keys
  once a day. The edge's documentation says the new key signs at once.
- **A guard that cannot read a command asks.** The push guard prompted the owner for commands that ran
  an inline script next to git. Scripts and git now go in separate commands.
