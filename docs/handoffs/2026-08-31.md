## PRINCIPLES

1. **A supervisor can make `disable` meaningless.** `disable` held for 4 minutes
   29 seconds before a `*/5` watchdog restarted the unit. Only `mask` held. Before
   declaring something stopped, ask what is watching it — and re-measure, because
   every reading taken in that window was contaminated and had to be discarded.
2. **Ask what a thing costs, not only whether it is up.** All twelve infra checks
   asked "is it reachable?". None asked "what is it consuming?". That is why 898
   CPU-hours went unnoticed for 33 days.
3. **Rate, never lifetime average.** A lifetime average understates a unit burning
   a core right now, and it is what made the gbrain reaper's red state unreachable.
4. **Red-test the checker, not just the thing checked.** The new CPU-burn check
   shipped green while a unit pegged a core; only the red test caught it.
5. **A policy label is not a guarantee.** "Security updates only" pulls the kernel
   and the GPU driver by default — 24 kernel/driver packages carry a
   security-pocket source. Prove the exclusion; do not trust the pocket name.
